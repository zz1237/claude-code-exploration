# Claude Project Standards & Instructions

This project follows best practices for Python development, focusing on clarity, maintainability, and reliability. All contributors are expected to adhere to the standards outlined below.

## Standards & Guidelines

Detailed standards are organized in the `rules/` folder:

- [Project Structure](rules/project-structure.md) — Code organization and folder layout
- [Coding Standards](rules/coding-standards.md) — PEP 8, type hints, docstrings, naming conventions
- [Dependency Management](rules/dependency-management.md) — Package management and virtual environments
- [Documentation](rules/documentation.md) — README, Markdown, and documentation practices
- [Version Control](rules/version-control.md) — Commits, branching, and repository maintenance
- [Notebooks](rules/notebooks.md) — Jupyter notebook best practices
- [Contribution Guidelines](rules/contribution-guidelines.md) — Code review and collaboration standards
- [Resources](rules/resources.md) — Useful references and documentation links

For questions or suggestions, contact the project maintainer.
