## Summary

Your skills directory contains two data processing scripts:

1. **convert_to_parquet.py** - Converts CSV files to Parquet format. Generally well-structured with good error handling, but has a **critical path bug** and some cross-platform compatibility issues.

2. **visualize.py** - Generates KPI analysis and visualizations. Well-organized with clear output, but contains **mathematical errors in KPI calculations** and lacks error handling for missing files.

---

## Critical Issues

### 1. **Path Case Sensitivity Bug** (convert_to_parquet.py, Line 92)
```python
source_base = r".\.claude\skills\fetchAPI\data"  # ❌ Wrong
```
The actual directory is `.claude\skills\fetchapi\data` (lowercase). This will cause `FileNotFoundError`.

**Fix:** Change `fetchAPI` to `fetchapi`:
```python
source_base = r".\.claude\skills\fetchapi\data"
```

---

### 2. **Incorrect KPI Calculations** (visualize.py, Lines 80 & 84)
```python
# ❌ Wrong - dividing by total number of stores, not averaging per store
avg_sales_per_store = fact_sales.groupby('store_sk')['net_amount'].sum() / len(dim_store)

# ❌ Same issue
avg_sales_per_product = fact_sales.groupby('product_sk')['net_amount'].sum() / len(dim_product)
```

The current code sums sales per store, then divides the entire sum by store count—giving a meaningless metric. You're calculating total sales divided by store count, not average per store.

**Fix:** Calculate mean of grouped sums:
```python
avg_sales_per_store = fact_sales.groupby('store_sk')['net_amount'].sum().mean()
avg_sales_per_product = fact_sales.groupby('product_sk')['net_amount'].sum().mean()
```

---

### 3. **No Error Handling for Missing Files** (visualize.py, Lines 54-57)
```python
fact_sales = pd.read_parquet(DATA_DIR / "fact_sales.parquet")
fact_returns = pd.read_parquet(DATA_DIR / "fact_returns.parquet")
# ... more file reads without try-except
```

If any Parquet file is missing or corrupt, the script will crash with no helpful message.

## Improvements

### 1. **Cross-Platform Path Handling** (convert_to_parquet.py, Lines 92-93)
```python
# Current - Windows-specific
source_base = r".\.claude\skills\fetchapi\data"
output_base = r".\.claude\skills\migrate\data"
```

**Better approach using `Path`:**
```python
source_base = Path(".") / ".claude" / "skills" / "fetchapi" / "data"
output_base = Path(".") / ".claude" / "skills" / "migrate" / "data"
```

Or use forward slashes (work on all OSes):
```python
source_base = "./.claude/skills/fetchapi/data"
output_base = "./.claude/skills/migrate/data"
```

---

### 2. **Module-Level Code Execution** (visualize.py, Lines 36-46)
```python
# Executes immediately when script is imported
MIGRATE_BASE = Path("./.claude/skills/migrate/data")
DATA_DIR = get_latest_data_folder(str(MIGRATE_BASE))
OUTPUT_DIR = Path("./.claude/skills/visualize/visualization")
print("=" * 70)
# ... more code
```

**Issue:** This prevents importing the script as a module and can fail before `main()` is called.

**Fix:** Wrap in `if __name__ == "__main__":` block:
```python
if __name__ == "__main__":
    MIGRATE_BASE = Path("./.claude/skills/migrate/data")
    DATA_DIR = get_latest_data_folder(str(MIGRATE_BASE))
    # ... rest of code
```

---

### 3. **Missing Logging** (convert_to_parquet.py)
The fetchapi SKILL.md specifies logging requirements, but the migrate script doesn't log its activities. Add logging for:
- Conversion start/end times
- File conversion details
- Errors with full tracebacks

### 4. **Exception Specificity** (convert_to_parquet.py, Line 85)
```python
except Exception as e:  # Too broad
```

**Better:**
```python
except (FileNotFoundError, pd.errors.ParserError, IOError) as e:
```
