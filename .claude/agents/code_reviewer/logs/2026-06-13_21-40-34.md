## Critical Issues

### 1. **Unsafe File Handling - convert_to_parquet.py (Line 92)**
**Severity:** MEDIUM

Raw strings with backslashes are used:
```python
source_base = r".\.claude\skills\fetchapi\data"
output_base = r".\.claude\skills\migrate\data"
```

**Issues:**
- Platform-dependent paths (Windows backslashes)
- Non-portable across Unix/Linux
- Better to use `Path` objects (already imported)

**Recommendation:**
```python
source_base = Path(".claude") / "skills" / "fetchapi" / "data"
output_base = Path(".claude") / "skills" / "migrate" / "data"
```

### 5. **Bare Except Clauses - convert_to_parquet.py (Lines 85, 114)**
**Severity:** MEDIUM

```python
except Exception as e:  # Line 85

except Exception as e:  # Line 114
```

- Too broad, catches system exits, keyboard interrupts
- No logging (inconsistent with fetch_data.py which uses logging module)

**Files:** convert_to_parquet.py, visualize.py

```python
def validate_dataframe(df: pd.DataFrame, expected_columns: set[str]) -> bool:
    """Validate DataFrame has expected columns."""
    missing = expected_columns - set(df.columns)
    if missing:
        raise ValueError(f"Missing required columns: {missing}")
    if df.empty:
        raise ValueError("DataFrame is empty")
    return True
```

### 5. **Inefficient Data Lookups - visualize.py**
**Lines:** 120-121, 137-138, 183-185

```python
sales_by_store['store_name'] = sales_by_store['store_sk'].map(
    dict(zip(dim_store['store_sk'], dim_store['store_name']))
)
```

Creates dictionary on each call. Better approach:

```python
store_mapping = dict(zip(dim_store['store_sk'], dim_store['store_name']))
sales_by_store['store_name'] = sales_by_store['store_sk'].map(store_mapping)
```

Or better yet, use merge:
```python
sales_by_store = sales_by_store.merge(
    dim_store[['store_sk', 'store_name']], 
    on='store_sk'
)
```

## Patterns to Store in Memory

### Pattern 1: Async API Client Management
**File:** fetch_data.py (lines 111-113)
**Pattern:** Context manager for httpx.AsyncClient
```python
async with httpx.AsyncClient() as client:
    tasks = [fetch_data_from_api(client, url, logger) for url in urls]
    results = await asyncio.gather(*tasks)
```
**Why:** Proper resource cleanup, efficient connection pooling
**Apply to:** Any async API fetching in the project

### Pattern 2: Proper Logging Setup
**File:** fetch_data.py (lines 18-45)
**Pattern:** Structured logging with file and console handlers
**Why:** Enables monitoring, debugging, and audit trails
**Apply to:** All scripts that need observability

### Pattern 3: Path Handling with pathlib
**File:** All files use pathlib.Path
**Pattern:** Prefer Path objects over string concatenation
```python
output_dir = Path(base_path) / folder_name
output_dir.mkdir(parents=True, exist_ok=True)
```
**Why:** Cross-platform compatibility, cleaner syntax
**Note:** Except convert_to_parquet.py which reverts to raw strings (anti-pattern)

### Pattern 4: Summary Statistics Reporting
**File:** fetch_data.py (lines 115-124)
**Pattern:** Collect results and report summary
```python
successful = sum(1 for success, _ in results if success)
failed = len(results) - successful
logger.info(f"Successful: {successful}, Failed: {failed}")
```
**Why:** Clear visibility into operation outcomes
**Apply to:** All batch operations
